# 芭蕾舞台大危机

一个面向青少年的冒泡排序互动游戏。项目使用原生 HTML、CSS 和 JavaScript，无后端、无在线依赖。

## 两个游戏

1. **手动排序**：点击相邻两位舞者交换位置，目标是排成 `6、5、4、3、2、1`。
2. **编程挑战**：选择比较条件、外层轮数和每轮比较次数，运行真实的冒泡排序过程。

错误程序也会被真实执行，并显示实际结果和简短提示。

## 本地运行

直接双击 `index.html` 即可离线运行。

也可以在项目目录运行：

```powershell
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

界面固定为 16:9，推荐使用 1920×1080 全屏体验。游戏正文、按钮、提示、统计和代码区文字均不小于 28px。

## 文件

- `index.html`：两个游戏的页面结构。
- `style.css`：紫金舞台、大字号 UI 和动画。
- `app.js`：手动交换、真实排序动作队列、运行控制和重置。
- `assets/`：舞台与六位舞者图片。
